# Cool Dawn

Soft morning light through misted glass, with muted sage accents and a coordinated dark interface.

![Cool Dawn desktop preview](preview.png?v=2026-10-12b)

## Install

For **Omarchy 4 with Omarchy Shell**:

```sh
omarchy theme install https://github.com/erikrjohansson/omarchy-cool-dawn-theme
```

## Update

To get new wallpapers and fixes, update your installed themes, then apply Cool Dawn again so Omarchy picks up the new files:

```sh
omarchy theme update
omarchy theme set cool-dawn
```

## Remove

Switch to another theme first (for example with `omarchy theme switcher`), then remove Cool Dawn:

```sh
omarchy theme remove cool-dawn
```

## The theme

- A foggy forest at dawn seen through misted glass, with condensation and drops on the pane.
- A top bar in the same deep green-gray as the windows.
- Deep green-gray surfaces, sage accents, soft ivory text, and pale sun-gold for warnings.
- Translucent menus and shell panels, coordinated terminal and editor colors, GTK 3 / GTK 4 styling, and Yaru icons with sage folders.

## Wallpapers

Two 6K (6016 × 3384) wallpapers: misted glass (default) and a misty lake. Switch between them with `omarchy theme bg next`, or from the Omarchy menu under Style → Background.

## Extras

- [Live wallpaper](live-wallpaper/) - a seamless looping rain-on-glass video of the background wallpaper (normal and small-drop versions) plus the Python script that renders it.
- [Obsidian](obsidian/) - a CSS snippet that brings the Cool Dawn palette to the AnuPpuccin Obsidian theme.
